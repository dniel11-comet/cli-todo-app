# 📝 CLI To-Do List Application

A lightweight and structured Command-Line Interface (CLI) application built with Python. Designed to streamline daily task management with clean code architecture and robust input validation.

---

## 🚀 Key Features
- **Task Management:** View all tasks, add new tasks, and delete tasks by item number.
- **Error Handling:** Gracefully handles, invalid inputs and prevents application crashes.
- **Clean CLI Menu:** Easy-to-use terminal interface for efficient daily task tracking.

---

## 🛠️ Tech Stack & Concepts
- **Language:** Python 3.x
- **COre Concepts:** Data Structures (Lists), Control Flow, Functions, Exception Handling ('try-except')
